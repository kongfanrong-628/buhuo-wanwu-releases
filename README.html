公众号AI工作台

v1.0.7 · Windows 桌面版
这是什么

一款跑在 Windows 上的桌面 AI 写作助手，专门给公众号和自媒体作者用。覆盖从找选题、写内容、配图封面、公众号排版到一键去 AI 味的全流程，一次下载、解压即用。

自动更新已升级为双源：GitHub 公开清单优先，不可达时自动降级到网盘兜底。

能帮你做什么
  • 贴图热点广场（本次新增）：打开贴图号首页就能看到 100 条真实公众号 10w+ 图文素材（图片＋标题＋阅读/分享数据，T+1 快照、非实时）。可按全量 / 指定赛道 / 关键词三种方式抓最新，一次整体只扣 1 次积分；抓到的内容自动存档 30 天，之后翻看免费。
  • 二创同款：看中某篇可单独拉整套图组参考，再走「参考图重新生图」换风格重绘成自己的图，不提供只改尺寸/去水印这类侵权做法；附成图合规自检。
  • 找选题：内置小红书、抖音低粉爆款灵感库，登录会员账号后按次扣积分（单次 5 分），不用自己申请任何 Key；公众号长文板块另增 10w+ 推荐栏。
  • 写内容：大纲、正文、改稿、配图、封面、公众号排版一条龙。
  • 去 AI 味：内置本地去 AI 味模型，成稿更自然、不像机器写的。
  • 管积分：设置页直接登录云端会员账号，查余额、看消费。

安装与运行

1. 下载压缩包后解压到任意文件夹（建议路径不含中文空格）；
2. 双击 不惑万物写作工坊.exe 启动；
3. 首次运行若被杀软拦截，请选择「允许」或加入白名单（程序为本地运行，无联网上传）；
4. 首次使用在「设置」里登录云端会员账号即可使用灵感库等云端功能。
